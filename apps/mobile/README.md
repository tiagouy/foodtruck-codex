# Aplicación móvil nueva

Aquí vivirá la nueva aplicación móvil. Todavía no se inicializa un proyecto para no elegir framework, autenticación ni distribución antes de cerrar el MVP y el contrato de la API.

La aplicación consumirá exclusivamente la API versionada del plugin `Foodtrucks UY Core`; no accederá a MySQL ni a las APIs PHP históricas.
