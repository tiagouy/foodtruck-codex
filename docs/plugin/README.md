# Foodtrucks UY Core

Plugin propio de WordPress que concentrará el dominio de la plataforma:

- foodtrucks, eventos y sus relaciones;
- sugerencias y flujos de moderación;
- perfiles, propiedad y reactivación de cuentas;
- pantallas de administración dentro de WordPress;
- API REST versionada para web y app;
- migración controlada desde las bases heredadas.

El código está en `plugins/foodtrucks-uy-core/`. Versión `0.10.0`: [muestra de usuarios aplicada localmente con perfiles](migracion-muestra-0.10.0.md); importación masiva y publicaciones pendientes. Incluye [almacenamiento propio de imágenes y respaldos](imagenes-0.9.1.md), [simulación de migración](migracion-usuarios-0.9.0.md), eventos, administración/API de foodtrucks, directorio/detalle web, imágenes reducidas y [cuentas propias](cuentas-0.8.0.md): registro, confirmación, login, perfil y recuperación/reactivación destacada. Todas las páginas del plugin comparten navegación pública y menú Mi cuenta. Ver [eventos](eventos-0.2.0.md) y [foodtrucks](foodtrucks-0.4.0.md).
